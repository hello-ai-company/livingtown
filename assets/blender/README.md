# Original waiting illustration

`create_training_guide.py` creates the original LivingTown houses, base, decorative dots and guide orb from Blender primitives. `training-guide.blend` and `public/media/training-guide.{webm,mp4,webp}` are outputs of this source, created specifically for this project. No external models, textures, audio, linked libraries or stock assets were used. The illustration does not depict a computed route or measurable progress.

The existing repository MIT license applies; no additional third-party asset license is introduced. Preserve the repository LICENSE notice. Blender itself is a build tool and is not distributed here.
