# LivingTown Clear Map v1 · 地図の見やすさと読み込みの改善

2026-10-12。Helpful Agent v1を保全した別コピーです。未公開・未push・未deploy。

## 使う人に変わること

- 地図の中を覆っていた凡例・投稿ボタン・ルートの説明を、地図の外側に配置しました。地図の拡大中も画面をスクロールして説明を読めます。
- 詳細・絞り込みは最初は閉じています。場所を選ぶと詳細が開き、閉じれば地図へ戻れます。スマホでも詳細を地図の上に重ねません。
- 「地図の場所を一覧から選ぶ」を追加しました。ピンを狙いにくい場合やキーボード操作でも、同じ絞り込み対象から場所を選べます。未確認・コミュニティ情報・期限切れの表示を保持します。
- SVGの代替地図では、すべてのピンの文字を常時重ねず、選択した地点のラベルを表示します。読み上げ用の説明とカテゴリ形状は残します。
- 拡大表示からEscapeで戻れます。詳細、地図だけ表示、拡大表示の順に閉じ、ボタンへフォーカスを戻します。拡大中のTabは地図内を移動します。
- 「架空の訓練・実際の通行と安全は未確認」を地図の外に常設しています。家族のSTOP、停止時の古い案内の無効化、8人分の条件、情報の鮮度、確認アシスト、レポート、バックアップは保持しています。

## 軽量化の範囲

MapLibre本体とCSSを地図表示時に読み込むよう分割しました。初めに表示される家族の画面で、地図の大きなプログラムをまとめて読み込む必要がなくなります。3Dも従来どおり明示操作時の遅延読み込みです。

選択地点だけが変わるとき、変化していないルート・世帯・詰まりの地図データを繰り返しsetDataへ送らないようにしました。地図の作り直し時は最新の5データを復元します。閉じた場所一覧の中身は描画しません。

測定値と条件はVERIFICATION.md、bundle-measurement.json、overlay-measurement.jsonを参照してください。バンドルのバイト数とモックでの呼び出し回数を比較したもので、実機の秒数・FPS・体感速度を測定した結果ではありません。

## 利用上の限界

この版は架空データによる訓練です。実際の施設の開設・通行・避難経路の安全は未確認です。現在地の利用は明示操作の一度だけで、追跡を追加していません。外部API費用・認証情報・公開環境の変更はありません。

実ブラウザの画面、スマホの実機表示、WebGL/3D、地図タイルのネットワーク取得、読み上げ実機は今回未検証です。DOMテストはレイアウトや実描画速度を保証しません。地図分割後もMapLibreを使う時点ではそのプログラムのダウンロードが必要で、総ダウンロード量が同じ割合で減るわけではありません。初期JSと3Dには大きなチャンクが残ります。
