## 実装した体験

- 常設の「自分と家族の状況」。既存のオリジナル人物を中央に置き、足・腕・頭周り・機器の電源を大きな文字ボタンで編集する。人物から診断や移動能力を推測しない。文字・キーボード操作が主で、任意3Dの失敗時も操作を続ける。
- 本人／家族1…の架空ラベル、本人を含む総数最大8人。部位ごとの条件は一人ずつ独立。追加、選択、削除、同じ条件での復元ができる。削除後に追加する人には新しいIDを割り当て、回答を混ぜない。復元も同時に参加する8人の上限を守る。選択中の1人を常時表示し、他の人は折りたたみ一覧から切り替える。本名・病名・生年月日・子供の属性は入力しない。
- 家族の条件は専用のReact reducerのメモリ内だけ。再読み込みで消える。既存の住民確認票・共有DB・AI・端末ストレージへ書き込まない。
- 各人の条件確認と全員の条件の明示確認後に比較。家族は一緒に移動し、全員の必須条件の交差で候補を出す。平均・自動分離はしない。根拠がない必須支援は候補を外し、希望なら要確認のメモにする。
- 手すり・荷物運搬・ゆっくり短い説明は未対応の支援メモ。現地の案内、電源、付き添いも未確認。未知を「不要」としない。誰のどの条件が理由かを経路ごとに表示する。
- 災害、緊急退避／滞在、福祉避難所の受入調整を区別する。施設・道路は自作の架空属性。実際の避難経路や安全を保証しない。

## 投稿で自動化する部分／本人が確認する部分

ローカルの決定的な処理で、投稿受信→入力検証・分類→追認と有効期限→固定デモの道路への対応→同じ確認済み家族条件で再計算→外れた／戻った候補と理由を表示する。実LLMや実配信を接続した機能ではない。「随時」はこのタブのローカル更新に限定する。

未確認の危険は警告として表示する。追認数は行政確認や安全保証ではない。通れるという投稿は通行不可の投稿を解除しない。撤回・期限切れは30秒の再開保留を置く。重複・古い版・逆順更新を除外し、撤回の記録を保つ。同時イベントは一度の候補再計算にまとめる。原文の指示を実行せず、原文を判断処理の台帳や更新トークンに残さない。

**候補再計算は自動、案内の変更は明示採用。** 採用済みの案内はそのまま残す。条件・投稿・期限が変わると「最新情報では未確認」の警告を出し、採用チェックを解除する。最新候補の理由・差分を本人が確認してから改めて採用する。バックグラウンドでタイマーが遅れた場合も、採用クリック時に期限を再確認する。

受信上限はローカル一覧64件、台帳128件、単一イベント配列64件。超過時は情報を一部だけ使って候補を出さず、比較・採用を停止して理由を表示する。一覧の超過から元と同じ一覧へ戻す場合も回復できる。

## 独立レビューと対応

実装担当とは別のレビュー担当がコードとテストを読み、次を指摘した。すべて対応し、限定再確認で新しい重大指摘はなかった。詳細は `artifacts/family-dashboard/independent-review.txt`。

1. 64件超の一覧が黙って欠落する → 上限を一貫させ、超過は明示して比較・採用を停止。64更新＋64撤回は分割受信後に一度再計算。回帰テストを追加。
2. 常設「自分の投稿」「管理」が閉じた従来画面を開かない → 明示ナビゲーション時に従来画面を開く。デスクトップで投稿画面の実操作も検証。
3. 超過前と同じ更新トークンに戻すと停止が解除されない → エラー中は同一トークンでも回復判定を行う。往復ケースを回帰に追加。

8人への拡張も同じレビュー担当が限定確認し、未解決の重大指摘はなかった。

実画像の確認で、モバイル3Dの縦横比が崩れる表示も直し、正方形キャンバスの比率をブラウザ検証へ追加した。人物はモバイルでも中央に表示する。

## 起動・再現

既存の依存を使う。キー設定や外部サービス接続は不要。

```sh
npm run dev -- --host 127.0.0.1 --port 4173
# http://127.0.0.1:4173/?training=local
```

人物の足で「階段を避けたい：必要」を選び、未入力をスキップして本人を確認。家族を追加し「長く歩かず休憩したい：必要」、腕の荷物運搬を「できれば希望」、頭周りの説明を「わからない」にする。家族を確認して全員のチェック後に計算する。南側を採用し、南側通行不可投稿を追加すると候補から外れるが案内は勝手に変わらない。撤回後に架空時点を31秒進めると候補を再評価する。

```sh
npm test
npm run test:assistant
npm run build
npm run preview -- --host 127.0.0.1 --port 4184
LIVINGTOWN_PREVIEW=http://127.0.0.1:4184 node artifacts/family-dashboard/browser-smoke.mjs
```

ブラウザ検証スクリプトはこの実行環境に既存のPlaywrightとChromiumを使う。別環境では先頭のPlaywright importおよびexecutablePathを、その環境の承認済みインストールに合わせる。取得拒否の迂回や新しいインストールは行っていない。
