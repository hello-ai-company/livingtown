# 家族に合わせた確認アシスト

この版は guided-glass-v2 を変更せず別コピーから作成したローカル訓練用ソースです。公開サイトには反映していません。

## 試す順序
1. ローカル訓練モードで「家族の準備ワークブック」へ進みます。
2. 「この家族なら、何から話そう？」の最大3項目と理由を確認します。
3. 家族の配慮で電源を「必要」にすると、電源の利用条件が優先され、その人の選択が根拠に表示されます。人数や移動・付き添いの条件でも順序と理由が変わります。
4. 「先に話し合う」「あとで」「今回は順番から外す」を自分で選びます。「確認項目を開く」で対応する既存チェックへ移動します。選択だけでは話し合い済みになりません。
5. 話し合った項目に既存チェックを付けると、次の未完了項目が優先候補に出ます。順番から外した項目も全9項目のリストに残り、いつでも選択を戻せます。
6. 家族条件・災害・目的・投稿・採用先などを変えると、選択が解除され、何が変わり何を見直すか表示されます。
7. 訓練レポートのプレビュー・テキスト保存・印刷にも、現在の選択と理由を含めます。保存は明示操作時だけです。

## 実装と安全境界
- 無料・オフラインの決定的なルール式支援です。実AI、LLM呼び出し、裏での作業、外部照会や通知を装いません。
- 優先順はユーザーが入力した架空の家族条件と既存ワークブックの話し合い状態から計算します。現地の危険度や安全性の順位ではありません。
- ワークブックの既存progressを共有し、話し合いの完了状態を別に持ちません。準備順の選択はメモリ内だけです。
- 既存workbookBasisによる失効を共用し、時計だけの更新では選択を消しません。根拠の変更・STOPで失効し、古い画面の選択はexpectedBasisで拒否します。条件を戻しても以前の選択を復活させません。
- セッションimportの既存remountにより選択を初期化します。STOPや復元・入力検証・同期fence・旧案内復活防止の実装には変更していません。
- 判断を先送りしたり順番から外しても、未知の配慮や未確認事項は消えません。安全・開設・受入・設備適合・支援確保の確認済みにはなりません。
- 医療診断、投薬判断、実連絡、個人情報入力、外部送信、追加API、通知権限、公開・デプロイはありません。

## 検証範囲
全Web test、backend test、evidence test、TypeScript、production buildを実行します。結果は同ディレクトリのVERIFICATION.mdとlogsを参照してください。
React静的レンダリングと状態遷移の自動試験を含みます。実ブラウザ画面・クリック・狭幅表示・読み上げの実機確認は未実施です。以前のブラウザsocket/ptrace拒否を迂回していません。見た目やキーボード操作の実機検証済みとは主張しません。
