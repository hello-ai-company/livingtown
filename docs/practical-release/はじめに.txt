LivingTown 実用訓練版（2026-10-12）

これは、公開済みの家族8人対応版を保全し、確認できた仕様から機能を再実装した完全ソースです。以前の未pushソースそのものを回収したものではありません。

今回追加・統合したこと
・千代田エリアを題材にした架空の地域訓練、避難場所と滞在先の区別
・8種類の障害物、未確認と明示的な訓練検証の区別
・「動けません」で直ちに停止。全員の再確認・再計算・再採用が必要
・匿名の協力者による区間確認の模擬練習。送信・現地派遣なし
・9項目の確認準備ワークブック、明示操作によるテキスト保存・印刷
・最大64 KiB、架空の1〜8人だけの厳格なJSONファイル入出力

今回の検証
・画面側などの自動テスト512件、バックエンド34件、施設情報19件が成功
・TypeScript、Vite build、独立したソースレビューが成功
・実ブラウザ、実機、印刷・ダウンロード操作、モバイルの見た目は未検証
・大きい3D用ファイルのビルド警告が残っています

起動
Node.js 22以降（今回使用：24）を用意し、ソースのフォルダーで以下を実行します。
  npm ci
  npm run dev -- --host 127.0.0.1
標準のアクセス先は http://127.0.0.1:4173 です。
保存版には.git履歴を含めません。バックエンドの全テストも実行する場合だけ、先に git init を実行してください（コミット・送信は不要です）。
実AI・共有DB・有料APIの設定は不要です。実際の個人情報を入れないでください。

重要な限界
訓練と確認の準備のためのソフトです。実際の道路、施設の開設・受入、避難経路の安全、救助や付き添いを確認・手配しません。
「停止」またはファイル読み込み後、このタブでは独立した従来の地図と外部エージェント操作を終了します。家族の訓練は全員の条件を確認して再開できます。

ソースの分割ファイルについて
第1部に起動に必要なソース・テスト・説明・パッチ・検証記録があります。
第2部以降は保全した過去の画像・証跡です。同じ場所へすべて展開すると完全な保存版になります。
過去のスクリーンショットやPASSという記録は、この版の実ブラウザ検証ではありません。
