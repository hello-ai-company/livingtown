# LivingTown 3分デモ台本

## 事前準備

1. `npm install`
2. `npm run seed`
3. `npm run dev`
4. ブラウザで表示し、右上の `管理ビュー` からデモデータをリセットする。

## 0:00 — 問題提起

「防災アプリは災害まで開かれません。でも、救う知識は『あの横断歩道は雨の日に水没する』という立ち話の中にあります。LivingTownは、その会話を街の経路に戻します。」

## 0:30 — 幕1：会話を地図にする

1. `街の記憶` を表示し、右側の `map tools` を見せる。
2. 「雨天の投稿を登録」をクリックする。
3. `contribute_knowledge` がActivityに出て、知識が確認待ちで地図に増えることを示す。
4. 同じカードの「追認する」を2回クリックする。
5. 「2票に届くと検証済みになります。WebMCPのツール面も、今はmapの3本だけです。」

## 1:15 — 幕2：一つの知識が道を変える

1. `避難訓練` をクリックし、`世帯A · 車椅子` を選択する。
2. 条件は `洪水 / 雨 / 昼` のまま「経路を計算」をクリックする。
3. 地図の緑の線が横断歩道を避けて南側へ回り、`この道を避けた理由` に日本語の理由と投稿内容が表示されることを見せる。
4. 「世帯には診断名や氏名を渡していません。車椅子という制約enumだけで、理由のあるルートを返します。」

## 2:00 — 幕3：街全体を振り返る

1. 「現地の詰まりを報告」をクリックする。
2. `振り返り` をクリックする。
3. `車椅子世帯の経路を見せて` の代わりに、世帯Aのフォーカスボタンをクリックし、`control_replay` のActivityを示す。
4. 「2Dフォールバックは常に動きます。PLATEAUの設定があれば同じツール面で3Dへ切り替えられます。」
5. 「同じ地図が、平時は暮らしを、有事は命を守る。フェーズフリー防災です。」

## 2:40 — WebMCPの締め

管理ビューに戻り、フェーズを `MAP → DRILL → REPLAY` と切り替える。右側のツール名が3本→3本→2本へ変わることを見せる。

「LivingTownは、エージェントに長い手順を暗記させません。今できることだけがツールとして存在し、街の状態そのものがプロトコルになります。」
