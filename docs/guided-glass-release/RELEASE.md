# LivingTown Guided Glass v2 — 2026-10-12

Local, unpublished upgrade of the preserved practical reimplementation. This does not recover the October 5–7 unpushed source. It does not update the public website.

## What changed

- Three clear entry points: family conditions, fictional comparison, preparation.
- A state-derived next action with explicit stopped, incomplete-data, unconfirmed, no-candidate, recheck and adopted-training states. It navigates only; it never confirms, resumes, calculates or adopts for the person.
- Short visible labels with decorative SVG icons. Important safety and confirmation wording stays visible.
- A sticky, text-labeled STOP that uses the same synchronous invalidation path as the existing emergency control. Resume remains a separate explicit confirmation.
- Optional fictional posts, obstacles and cooperators grouped in a native disclosure. Regional supporting evidence is separate; the fictional/non-real-world boundary remains visible at the top. File import remains fully visible, preserving its asynchronous cancellation contract.
- Scoped Liquid Glass styling with solid readable surfaces, one optional small backdrop blur, compact mobile navigation, focus outlines, and reduced motion/transparency, high contrast and forced-colors fallbacks. No animation, new package, API, permission or network service was added.

## Safety preserved

The family reducer, eight-person limit, stale-result/revision checks, click-time clocks, 5-minute observations, 30-second reopening hold, 60-second cooperator review, STOP/native legacy disposal, strict session parser and preparation workbook remain unchanged. All actual designation, opening, admission, travel and support remain unverified. A step number or adopted fictional route does not indicate actual safety or completed preparation.

## Verification limits

Automated checks and independent source review are documented separately in VERIFICATION.md. No actual browser or device execution was attempted for this upgrade because previous execution was denied. CSS/SSR checks are not evidence of pixel layout, real keyboard use, screen-reader announcements, browser focus behavior, native WebMCP, download or printing. Those remain manual acceptance gates. Existing large optional 3D chunks remain a performance limitation.

## Use and rollback

Node.js 22+; the same local setup described in the main README applies. Do not add live credentials or real personal data to try the fictional exercise.

The updated first archive retains the `livingtown-practical/` folder so it can be combined with the unchanged historical parts 2–4. Extract into a fresh folder, not over a working copy. Keep the previous first archive for a complete rollback. The old three historical archives remain byte-identical and do not need replacing.

`guided-glass-v2.patch` is relative to the exact previous practical release, not the GitHub commit. In a clean exact previous release, `git apply --check guided-glass-v2.patch` verifies compatibility, then `git apply guided-glass-v2.patch` applies it. `git apply --reverse --check` and `git apply --reverse` undo it only if no later edits conflict. Prefer extracting the preserved previous first archive for rollback. The older `livingtown-practical.patch` and original preservation metadata are historical v1 materials and are kept under their original names; they do not describe v2.
